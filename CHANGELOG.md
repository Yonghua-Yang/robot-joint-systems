## Change Categories

Future changes may use the following categories:

### Added

New documents, tools, simulations, datasets, diagrams or repository sections.

### Changed

Meaningful revisions to existing engineering methods, definitions or structures.

### Corrected

Corrections to technical content, terminology, formatting or calculations.

### Removed

Content that is obsolete, duplicated, incorrect or no longer suitable for public use.

### Security and Confidentiality

Changes related to public-content review, removal of sensitive information or improvement of confidentiality controls.

---

## Maintenance Principles

The changelog should record meaningful engineering progress rather than every minor edit.

A change should normally be recorded when it affects:

- Repository structure
- Engineering scope
- System architecture
- Control methods
- Metric definitions
- Verification methods
- Engineering decisions
- Tool functionality
- Public-content confidentiality
- Version-release readiness
