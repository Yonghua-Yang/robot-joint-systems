# References

This file records public technical references used in the Robot Joint Systems engineering knowledge base.

Only publicly available sources should be included.

A reference should be added when it materially supports an engineering definition, architecture, calculation method, test method or technical conclusion.

---

## Reference Principles

References should preferably come from:

- International standards organizations
- Industry associations
- Academic papers
- University publications
- Official manufacturer documentation
- Official protocol documentation
- Technical books
- Reputable open-source projects
- Public engineering articles

References should not come from:

- Internal company documents
- Confidential specifications
- Non-public test reports
- Customer documents
- Supplier-confidential materials
- Unverified screenshots
- Anonymous technical claims
- Materials without a traceable source

---

## Citation Requirements

When a document uses an external technical source, it should identify:

- Author or organization
- Document title
- Publication or revision date
- Document number or version, when available
- Public source location
- Access date, when relevant
- The topic supported by the reference

A reference should only be listed when it has actually been reviewed or used.

---

## Reference Format

Use the following general format:

**Reference ID**

- Organization or author:
- Title:
- Document number or version:
- Publication date:
- Public source:
- Access date:
- Related repository topic:
- Notes:

Example:

**REF-XXX**

- Organization or author: Public organization or author name
- Title: Public document title
- Document number or version: Public revision information
- Publication date: YYYY-MM-DD
- Public source: Official public webpage or publication
- Access date: YYYY-MM-DD
- Related repository topic: System architecture, control or verification
- Notes: Brief explanation of how the reference is used
