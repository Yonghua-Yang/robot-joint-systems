# Overview

This section introduces the scope, system boundary and core concepts of robotic joint systems.

## Purpose

The purpose of this section is to establish a common system-level understanding before discussing detailed architecture, control, communication and verification topics.

## Main Topics

- Definition of a robotic joint system
- System boundary
- Main hardware and software components
- Input and output interfaces
- Signal and energy flow
- Engineering capability map
- Terminology and abbreviations
